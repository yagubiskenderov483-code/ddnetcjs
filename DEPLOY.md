# Деплой на Render (с телефона, без терминала)

Шаги занимают 5 минут.

## 1. Зарегистрируйся на Render

Открой в браузере телефона: **https://render.com** → **Get Started** → логин через GitHub (тот же аккаунт где `ddnetcjs`).

## 2. Создай сервис

На дашборде Render:

1. Жми **New +** (кнопка сверху справа)
2. Выбери **Blueprint**
3. **Connect a repository** → выбери `yagubiskenderov483-code/ddnetcjs`
4. Render увидит файл `render.yaml` и покажет: 1 Worker `tde-bot` + диск 1 GB
5. Жми **Apply**

## 3. Жди деплой

На странице сервиса `tde-bot`:

* **Events** — покажет «Deploy started» → «Build successful» → «Deploy live» (2-4 минуты)
* **Logs** — если видишь `TDE bot starting · owner=8985115640` — всё поднялось

## 4. Проверь в Telegram

Открой [@cusisnsfvbot](https://t.me/cusisnsfvbot) → увидишь сообщение **«🟢 Бот запущен»**.

Напиши `/start` — должно прийти меню.

## 5. Первый логин

```
/login +79991234567
```
(твой номер, к которому привязан Telegram)

Telegram пришлёт код в системный чат **«Telegram»** в твоём клиенте.

```
/code 12345
```

Если 2FA:
```
/pw твой_пароль
```

## 6. Экспорт

```
/export
```

Бот напишет прогресс, пришлёт ZIP. Больше 50 MB → частями.

## Тонкости

**Free-тариф Render засыпает** через 15 минут неактивности → бот не будет отвечать. Два решения:

1. Апгрейд на Starter ($7/мес) — крутится всегда
2. Или напиши боту `/start` — он проснётся и ответит через ~30 секунд

**Если бот не отвечает после деплоя:**
* Открой в Render → `tde-bot` → **Logs**
* Скинь мне последние строки лога

**Диск** — сессия Telethon сохраняется в `/data/owner_session.session` на 1 GB диске. Диск не удаляется при редеплое — повторный логин после апдейта не нужен.

**Как смотреть логи с телефона:**
Render Dashboard → сервис `tde-bot` → вкладка Logs. Там streaming.

**Сменить код бота:**
Push в `main` → Render автоматически передеплоит.
