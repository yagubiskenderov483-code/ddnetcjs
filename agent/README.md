# tde-agent — локальный экспортёр

Запускается на машине владельца аккаунта. Авторизация Telegram проходит
локально в этой консоли — коды и пароль 2FA никуда кроме серверов
Telegram не отправляются.

## Что делает

1. Берёт одноразовый pairing-код с сайта TDE.
2. Просит номер телефона и код из Telegram (локально).
3. Полностью скачивает: профиль, контакты, все диалоги, сообщения,
   фото, видео, голосовые, круглые видеосообщения, документы, стикеры,
   анимации.
4. Рендерит HTML + JSON в структуре, совместимой с Telegram Desktop Export.
5. Пакует в ZIP, считает sha256.
6. Загружает ZIP на бэкенд по chunked-upload.
7. Бэкенд проверяет контрольную сумму и пересылает архив в
   Telegram-бота владельца сервиса.

## Установка

```bash
pip install -e .
# или (из корня репо):
pip install ./agent
```

Для аккаунтов с 2FA дополнительно пригодится `cryptg` для ускорения
скачивания медиа — он уже в зависимостях.

## Запуск

Сначала на сайте TDE нажмите «Начать экспорт» — получите 6-значный
pairing-код (живёт 15 минут).

```bash
export TG_API_ID=1234567
export TG_API_HASH=0123456789abcdef0123456789abcdef
export TDE_API_BASE=https://api.tde.yourdomain.com

tde-agent pair AB12CD
```

Опции:

```
--no-media            не скачивать медиафайлы
--no-messages         только профиль и список диалогов
--limit N             последние N сообщений на диалог (0 = без лимита)
--max-file-mb MB      пропускать медиа крупнее (default 50)
--session PATH        файл сессии Telethon (default ~/.tde-agent/session)
```

## Структура результата (совместимо с Telegram Desktop Export)

```
.
├── profile.json
├── contacts.json
├── dialogs.json
├── index.html             — главная страница
├── README.md
└── chats/
    └── <id>_<name>/
        ├── messages.json
        ├── messages.html
        ├── photos/
        ├── video_files/
        ├── voice_messages/
        ├── round_video_messages/
        ├── files/
        ├── stickers/
        └── animations/
```

Откройте `index.html` в браузере — получите интерактивный просмотр.

## Безопасность

* Коды авторизации и пароль 2FA вводятся локально, в этой консоли.
* Файл сессии Telethon лежит у вас в `~/.tde-agent/session`.
  Удалите его, чтобы разорвать авторизацию.
* Все временные файлы и ZIP агент удаляет после загрузки на бэкенд.
* На сервер уходит только готовый ZIP и статус прогресса — никаких
  кодов, паролей, ключей сессии.
