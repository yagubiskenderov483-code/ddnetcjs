# Локальный агент — установка и запуск

## Что это

tde-agent — это CLI-утилита, которая запускается на машине владельца
Telegram-аккаунта. Она делает полный экспорт данных в формате,
совместимом с Telegram Desktop Export, и загружает архив на сервер TDE
через безопасный chunked-upload.

## Почему локально

Спек требует: не передавать коды авторизации Telegram на сервер.
Единственный способ соблюсти это и всё равно иметь полный экспорт —
выполнить авторизацию и выгрузку на машине пользователя, а серверу
отдать уже готовый архив.

## Установка

Требуется Python 3.10+.

Из репозитория:

```bash
cd agent
pip install -e .
```

Если нужен быстрый скачиватель медиа — `cryptg` уже включён в зависимости.

## Получение API ID / API Hash

1. Открыть [my.telegram.org](https://my.telegram.org) → API development tools.
2. Создать приложение (тип Desktop).
3. Скопировать api_id и api_hash.

```bash
export TG_API_ID=1234567
export TG_API_HASH=0123456789abcdef0123456789abcdef
```

## Запуск экспорта

1. На сайте TDE жмёте «Сгенерировать pairing-код» — получаете 6-значный код.
2. На своей машине:

```bash
export TDE_API_BASE=https://api.tde.yourdomain.com   # адрес бэкенда
tde-agent pair AB12CD
```

3. Агент попросит номер телефона и код из Telegram (приходит прямо
   в ваш клиент Telegram). Для аккаунтов с 2FA — попросит пароль.
   Всё вводится локально.

4. Агент выгружает данные, пакует в ZIP, считает sha256, грузит на бэкенд.

5. Бэкенд проверяет контрольную сумму и отправляет архив в
   Telegram-бота владельца сервиса.

## Опции

```
--no-media            не скачивать медиафайлы (только профиль + сообщения в тексте)
--no-messages         только профиль и список диалогов
--limit N             последние N сообщений на диалог (0 = без лимита)
--max-file-mb MB      пропускать медиа крупнее (default 50)
--session PATH        путь к файлу сессии Telethon (default ~/.tde-agent/session)
```

## Что экспортируется

| Данные | Статус |
|---|---|
| Информация профиля | ✅ |
| Контакты | ✅ |
| Личные чаты | ✅ |
| Группы | ✅ |
| Каналы | ✅ |
| История сообщений | ✅ (любая глубина, параметр --limit) |
| Фотографии | ✅ |
| Видео | ✅ |
| Голосовые | ✅ |
| Видеосообщения (круглые) | ✅ |
| Документы | ✅ |
| Стикеры | ✅ |
| Анимации (GIF) | ✅ |

Секретные (end-to-end) чаты не экспортируются — они по дизайну
недоступны ни через MTProto API, ни через Telegram Desktop.

## Безопасность

* Коды, пароли и ключи сессии остаются на вашей машине.
* Файл сессии Telethon лежит в `~/.tde-agent/session`.
  Удалите его, чтобы разорвать авторизацию.
* Все временные файлы и ZIP агент удаляет после загрузки на бэкенд.
* Канал агент → бэкенд авторизуется HMAC-токеном, полученным при
  обмене pairing-кодом (одноразовый, живёт 4 часа).
